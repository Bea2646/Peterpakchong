# 🏡 peterpakchong.com (บ้านปีเตอร์@ปากช่อง)

เว็บไซต์ทางการของ **บ้านปีเตอร์@ปากช่อง** — บริการบ้านพักตากอากาศ พูลวิลล่า และห้องพักท่ามกลางธรรมชาติ อำเภอปากช่อง จังหวัดนครราชสีมา

---

## 📌 คุณสมบัติของเว็บไซต์

- **หน้าแรก (`index.html`)**: แนะนำบ้านพัก, บรรยากาศธรรมชาติ (แกลเลอรีภาพกลางวันและกลางคืนกว่า 100 ภาพ), สถานที่ท่องเที่ยวใกล้เคียง, แผนที่ และช่องทางติดต่อ
- **หน้าบ้านพักแต่ละหลัง**:
  - `bighouse.html` — บ้านหลังใหญ่ (รองรับผู้เข้าพักกลุ่มใหญ่)
  - `house1.html` — `house6.html` — บ้านปีเตอร์ 1 ถึง บ้านปีเตอร์ 6 พร้อมสิ่งอำนวยความสะดวกครบครัน
- **หน้าสถานที่ท่องเที่ยวใกล้เคียง**:
  - `nearby2.html` — สวนซ่อนศิลป์ (Secret Art Garden)
  - `nearby3.html` — วัดป่าเขาภูหลวง (หลวงปู่ไม)
  - `nearby6.html` — ทองสมบูรณ์คลับ
  - `nearby7.html` — Take Me Home Park Khaoyai
  - `nearby8.html` — อุทยานแห่งชาติเขาใหญ่
  - `nearby9.html` — อุโมงค์ต้นหางนกยูง
- **SEO & Search Engines**:
  - รองรับ Open Graph, Twitter Cards, Schema.org Structured Data
  - มี `sitemap.xml` และ `robots.txt` พร้อมสำหรับการทำดัชนีของ Google
- **รองรับทุกหน้าจอ (Fully Responsive)**: รองรับการแสดงผลทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน พร้อมปุ่มติดต่อด่วน (Mobile CTA)

## 🚀 โครงสร้างโฟลเดอร์

```text
├── index.html            # หน้าหลัก
├── bighouse.html         # หน้าบ้านหลังใหญ่
├── house1.html - 6.html  # หน้าบ้านพักหลังที่ 1-6
├── nearby2,3,6,7,8,9.html# หน้าสถานที่ท่องเที่ยวรอบข้าง
├── sitemap.xml           # Sitemap สำหรับ Search Engines
├── robots.txt            # กฎ robots.txt
├── deploy.ps1            # สคริปต์อัตโนมัติสำหรับ Deploy ขึ้น Cloudflare Pages
├── image/                # รูปภาพหลักและรูปภาพสถานที่ท่องเที่ยว
├── 12/, 34/, 56/, Big/   # รูปภาพของบ้านพักแต่ละหลัง
├── View/, Darkview/      # รูปภาพบรรยากาศช่วงกลางวันและค่ำคืน
└── js/                   # สคริปต์การทำงาน
```
